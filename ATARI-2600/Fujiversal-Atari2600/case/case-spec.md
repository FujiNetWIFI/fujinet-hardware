# Fujiversal-Atari2600 Rev0 shell

`Fujiversal-Atari2600-Shell.scad` is a two-piece clamshell over the
full-width part of the board. The tab and shoulders stay bare and go into
the console slot exactly as the FujiPlusCart prototype board did.
`board-anchors.scad` is generated by `tools/gen_pcb.py` from the placement,
so the openings follow the board.

| | |
|---|---|
| Outside | 58.2 x 70.5 x 10.2 mm (the ESP32-S3 antenna pocket makes the top-left step) |
| Front half | plate on the console-front (B.Cu, label) face; rim up to the board, screw counterbores, antenna rest, 44 x 36 mm label recess |
| Rear half | walls + roof over the component (F.Cu) face; RESET hole (5 mm), pin-holes for BOOTSEL / S3 EN / S3 BOOT, light holes for the WS2812 and the RP LED |
| Top edge | USB-C opening sized for a plug overmold; microSD slot with a finger notch |
| Bottom edge | the board exits between the halves; the shell's bottom face is ~25.5 mm above the contact edge |
| Fasteners | 4x M3x10 pan head from the front into the rear bosses (2.6 mm pilot for self-tapping, or open to 4.0 mm for heat-set inserts) |

Export:

```
openscad -D 'part="front"' -o front.stl Fujiversal-Atari2600-Shell.scad
openscad -D 'part="rear"'  -o rear.stl  Fujiversal-Atari2600-Shell.scad
```

Print both halves outside-down, no supports, 0.2 mm layers, PETG or PLA.

**VERIFY on a console before printing more than one:**
- The shell must clear the console top before the fingers seat. The
  prototype carried parts from about 27.5 mm above the edge and seated;
  this shell starts at about 25.5 mm. If it bottoms out, raise `bottom_y`
  (and keep every part above it in `tools/placement.py`).
- 2600 Jr / 7800 slot surrounds are shaped differently from the heavy-sixer
  and 4-switch; try each model you want to support.
