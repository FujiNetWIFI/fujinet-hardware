# Fujiversal-Atari2600 Rev1 shell

`Fujiversal-Atari2600-Shell.scad` is a two-piece clamshell over the
full-width part of the board. The tab and shoulders stay bare and go into
the console slot exactly as the FujiPlusCart prototype board did.
`board-anchors.scad` is generated by `tools/gen_pcb.py` from the placement,
so the openings follow the board.

| | |
|---|---|
| Outside | 58.2 x 64.1 x 10.2 mm (Rev1: the ESP32-S3 antenna is flush with the board edge, no pocket) |
| Front half | plate on the console-front (B.Cu, label) face; rim up to the board, screw counterbores, 44 x 36 mm label recess |
| Rear half | walls + roof over the component (F.Cu) face; RESET hole (5 mm), pin-holes for BOOTSEL / S3 EN / S3 BOOT, light holes for the WS2812 and the RP LED |
| Top edge | USB-C opening sized for a plug overmold |
| Right edge | microSD slot with a finger notch (Rev1 moved the socket off the top edge, away from the antenna) |
| Bottom edge | the board exits between the halves; the shell's bottom face is ~25.5 mm above the contact edge |
| Fasteners | 4x M3x10 pan head from the front into the rear bosses (2.6 mm pilot for self-tapping, or open to 4.0 mm for heat-set inserts) |

Export:

```
openscad -D 'part="front"' -o front.stl Fujiversal-Atari2600-Shell.scad
openscad -D 'part="rear"'  -o rear.stl  Fujiversal-Atari2600-Shell.scad
```

Print both halves outside-down, no supports, 0.2 mm layers, PETG or PLA.

**VERIFY on a console before printing more than one:**
- The shell must clear the console top before the fingers seat. The
  prototype carried parts from about 27.5 mm above the edge and seated;
  this shell starts at about 25.5 mm. If it bottoms out, raise `bottom_y`
  (and keep every part above it in `tools/placement.py`).
- 2600 Jr / 7800 slot surrounds are shaped differently from the heavy-sixer
  and 4-switch; try each model you want to support.

# Cart shell (norm8332 remix)

`Fujiversal-Atari2600-CartShell.scad` is a full-size 2600 cartridge: the
whole board, tab included, goes inside, the tab sits in the open bottom end
like any cart, and the body drops into the slot, so the slot-clearance
question above does not arise. It is a re-model of **"Atari 2600 Cartridge
Shell - Easy Print" by norm8332**
(<https://www.thingiverse.com/thing:1790785>, Creative Commons Attribution):
the outline, walls, floors, edge fillets, screw bosses, countersinks, holder
channel, end-label recess and holder were measured from norm8332's REV_3
top/bott and REV_2 holder STLs and redrawn in OpenSCAD (the STLs themselves
are not used or included). It reads the same `board-anchors.scad`.

| | |
|---|---|
| Outside | 81.49 x 98 x 20.22 mm (norm8332's), longer only if `stretch` > 0 |
| Board | centred; contact edge `edge_recess` (6.5 mm) inside the open end; B.Cu 11.25 mm from the front face (norm8332's board plane); 10.9 mm from each side wall; top edge 1.1 mm under the end wall |
| Front half | label face, flat outside (full-face label) + 0.8 mm end-label recess; 4 posts (6 mm) press the B.Cu face at the mounting holes; 2.5 mm screw pilots; microSD card shelf |
| Rear half | screw face: 4 countersunk 3.5 mm holes; 4 standoffs (4.6 mm) to F.Cu with 2.9 mm pins into the NPTH holes; 5.4 mm from F.Cu to the floor (tallest part 3.26 mm); RESET flexure button with a nub to 0.2 mm above the switch; pin-holes for BOOTSEL / S3 EN / S3 BOOT; light holes for the WS2812 and the RP LED |
| Holder | norm8332's bulkhead in the channel 24 mm up: the shoulders pass through its 56.2 x 2.4 mm slot, grip nubs leave 1.8 mm centred on the board; prints flat |
| Top end | USB-C mouth 13 x 7.2 mm for the plug overmold (cuts through the end label) |
| Right side | microSD slot with a guided tunnel across the 11 mm from the board edge to the wall |
| Fasteners | 4 countersunk wood screws (#4 x 1/2", as norm8332) or M2.5-M3 x 12 self-tapping, from the rear face |

Changes from norm8332's shell: its PCB ribs (rear) and clamp posts (front)
are gone (they sit inside the Rev1 footprint), the Rev1 standoffs, posts and
openings above are new, the holder slot is centred on the board plane with
nubs on both faces, and the shell can lengthen (`stretch`) for a deeper edge
recess.

Export:

```
openscad -D 'part="front"'  -o cart-front.stl  Fujiversal-Atari2600-CartShell.scad
openscad -D 'part="rear"'   -o cart-rear.stl   Fujiversal-Atari2600-CartShell.scad
openscad -D 'part="holder"' -o cart-holder.stl Fujiversal-Atari2600-CartShell.scad
openscad -D 'part="check"'  -o /tmp/check.stl  Fujiversal-Atari2600-CartShell.scad   # must say "top level object is empty"
```

Print all three outside-down (the holder flat, posts up), no supports, 0.2 mm
layers. Assemble: board onto the rear standoffs (pins through the holes),
holder into its channel with the board's shoulders through the slot, front
half on, screws from the rear.

**microSD:** the card is pushed in and released through the side slot with a
thin tool (a guitar pick); it sits about 13 mm inside the outside of the wall.

**VERIFY before printing:**
- **`edge_recess`**: measure an original Atari cart from the bottom face of
  the shell to the tips of the PCB fingers and set it. 6.5 mm is an estimate.
  Err low: an edge recessed too deep keeps the fingers from seating. Above
  7.3 mm the shell lengthens itself (`stretch`, echoed on render) so the board
  still fits under the end wall.
- Print the rear half first and dry-fit the board on the standoffs.
- Seat it in every console model you want to support.
- WiFi RSSI in the shell (the nearest screw is ~7.5 mm from the S3 antenna;
  nylon screws if it matters).
